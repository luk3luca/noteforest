In the Dock

What was wrong. Round 5 used a page of 512 in a 1024 canvas — a quarter of the area, floating in a dark field. Round 6 went edge to edge. Neither is an icon: the squircle is 824, and the object inside it should leave a margin you can see but not a gap you fall into.

My pick: inset 88. The page keeps a visible border on all four sides, the fold stays clear of the squircle's curve, and at 16 px the tile is still mostly paper — which is what makes it recognisable.

Lab only, no application code. The 16 px variant drops the text lines and the fold highlight; only the silhouette remains.
