Code fences and inline code: the behaviours side by side.

1 · Code fences

Put the caret in the first, empty line, type three backticks (optionally a language, e.g. ```python) and press Enter. The three variants differ in what happens to the text that already exists below, and in how you leave the block.

2 · Inline code

Type in the source. The same text is rendered under the two rules, so an unclosed backtick shows the difference immediately.
