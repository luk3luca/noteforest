Find bar, without the extras

The floating bar is the VS Code widget minus the toggles: query, 1 of 4, previous and next, close. No case, whole-word, regex or menu. The sidebar is the browsing view: snippets of the blocks where the word appears.

  • Bar = find nowType, see the count, move with the arrows, Esc.
  • Sidebar = browseEvery occurrence, with the phrase around it.
  • One engineCase-insensitive, literal text, the open note only.

How it behaves

Case-insensitive, literal, no regex, no replace, open note only. One result per occurrence; the sidebar groups them by chapter and block with a snippet; the bar counts them and moves through them.

⌘F open · ↑↓ move · ↵ / ⇧↵ next/previous · ⌘G / ⌘⇧G · esc close and restore.

Build order. The bar is phase 6. The sidebar Search is the activity bar’s future “Search” section: same engine, a persistent list. This lab is the design for both; the code slice can start with the bar.

Lab only: no application code. The bar is 40 px high with 28 px controls and the app's 4/8 px radii; the sidebar snippets clamp to two lines at 264 px.
