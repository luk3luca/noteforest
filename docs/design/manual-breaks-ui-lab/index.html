Manual breaks — the cut, the control, the list

The paginator already honours a break and already warns when it cannot. What is missing is a control that tells the truth, a list that makes breaks findable, and cleanup. A break is a page boundary at the y of a block's row, not a property of a branch.

1 · What the cut does

On the left, a break on a top-level block: the row and everything below move down. On the right, the same block is a child placed beside its parent — it shares the parent's y, so a break there would cut before the parent. That is why the control is not offered there.

3 · The Breaks section

A fifth activity-bar entry in the sidebar rhythm: title, count, plain navigation rows — a break is not a result, so no card. The page number is the current pagination, recomputed live.
