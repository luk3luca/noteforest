## Summary

Plain Backspace now stays inside the active block. The pure contract is
`native | stay`: a collapsed caret at the very start of a non-atomic block body
returns `stay` (empty or not), every other position returns `native`, and code
blocks, tables, list items and blockquotes stay native. The keymap swallows the
key only for `stay`; the previous-block focus branch, `visibleBlockIds`, and
`blockBodyIsEmpty` are gone. `⌘Backspace` and Delete remain the only structural
delete paths.

A selected inline node is not a collapsed caret: `NodeSelection.empty` is `true`,
so the keymap also requires the selection not to be a `NodeSelection`. Otherwise
a selected image at the start of a block would be swallowed like a caret.

- `apps/desktop/test/backspace.test.ts` — new contract coverage: start empty →

- `tests/e2e/m2-editor.test.mjs` — the old assertion (Backspace on an empty

  Backspace at offset 1 proves native editing inside the block still works and

## Risks and notes

- The macOS contenteditable does not bind a native Home caret move in this
  build, so the UI helper positions the caret by clicking before the first
  character rather than by pressing Home. The assertion itself is the caret
  offset, not the input method.
- Paragraph joins inside a block are now only reachable when the caret is not at
  the first paragraph of the block body; a Backspace at the very start of the
  first paragraph is the swallowed boundary case by design.
- UI edge behavior for selected inline nodes is guarded by the `NodeSelection`
  check; no new UI test covers image deletion, which is outside this brief.
